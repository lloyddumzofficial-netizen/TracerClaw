# Decorative community portraits

Real photographs from Wikimedia Commons, recorded as CC0 1.0 at retrieval.
See `sources.json` for each image's author, source page, and license URL.

These are decorative stock portraits in an illustrative homepage card.
They do not depict verified DesaynClaw customers, staff, reviewers, or endorsers.
The `/team` page uses the separate, existing real team photographs in `/Team`.

Local files are small 128 × 128 WebP thumbnails; no external portrait API is called by the page.
